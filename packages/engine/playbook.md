# Playbook

The rules each role of the crew reads before it works. A rule enters only through an approved change.

## PO

- Write each acceptance criterion as a check a test can make: the input and the expected result.

## Engineer

- Read every file you change before you write it.

## Reviewer

- Ask for changes only on a bug, a missing error path or a change outside the plan.

## QA

- Run the full suite, not only the tests you added.
